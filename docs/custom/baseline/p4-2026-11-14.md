## 3. 两个新学到的硬约束

1. **Remote 边界类型必须从非根 `./types` 子路径导出**。`GitStatus` 等 DTO 放在包根导出时，生成器报 `Remote boundary type … must be exported from a public non-root type subpath`。已在 `@nange/dsh-api-git` 增加 `src/types.ts` 与 `"./types"` export。
2. **Remote 服务键不能与能力服务键相同**。`GitController extends TypertRemoteService` 时若 `super(ctx, 'git')`，会与 Provider 的 `ctx.git` 冲突（`service "git" has been registered at <GitLocal>`）。正确写法是 `super(ctx, 'gitController', { namespace: 'git' })`：服务键唯一，Remote 命名空间仍是 `git`。

## 4. 运行时路径

- Client 挂载：`ctx.remote.$mount(remote)` → `ctx.inject(['remote.git'], scope => …)`；面板通过 slot 的 `inject(sessionId)` 拿到绑定该 Session 的 API；
- Session → cwd：Controller 注入 `sessions`，读 `sessions.get(sessionId)?.header.cwd`；无 cwd 返回 `git/workspace-unavailable`；
- Git 执行：`ctx.subprocess.resolveExecutable` + `spawn`，`stdin: ignore`、stdout/stderr 收集上限、`GIT_TERMINAL_PROMPT=0`、`GIT_OPTIONAL_LOCKS=0`、调用方 signal 透传、15s 默认超时。
