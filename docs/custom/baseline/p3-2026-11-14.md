# P3 记录：Mermaid 客户端插件（2026-11-14）

依据：[03 §3 P3](../03-实施计划.md#p3-mermaid-插件试点3-人日)。插件仓 commit `eb901aa`。

## 1. 产物

`@nange/dsh-plugin-mermaid`（bundle）+ `@nange/dsh-client-ui-mermaid`（客户端插件）：

- 注册 `conversation.chat.markdown.fence` 的 `hoc` 层，`key: 'mermaid'`，只接管 `mermaid` 围栏；
- 流式围栏先回落代码块，渲染失败回落代码块并显示错误；
- 监听 `body[data-ds-dark-theme]` 变化，按主题重绘；
- 点击图表打开全屏视图：按钮/滚轮缩放（0.25–4）、拖拽平移、1:1 重置、Escape 关闭；
- `globalThis.__DSH_P3_RENDER__` 暴露渲染入口供 E2E 探针使用；
- 构建：esbuild 打成 loader closure-factory，Host 入口单独产出 `lib/index.js`。

## 3. 已知限制

1. **包体 7.3 MB**：Mermaid 全量内联，包含所有图类型与 d3 依赖。正式发布应：
   - 只引入所需图表（`mermaid/core` + flow/sequence 等），或
   - 用 loader 的 chunk 机制懒加载（需要适配官方 client preset 的分包产物）。
2. **尚未验证「真实聊天消息中的围栏」**：当前验证覆盖「插件激活 + 渲染函数 + 安装」，未覆盖「一条包含 mermaid 围栏的会话消息在聊天区渲染」。
   - 激活本身已证明 slot 注册成功（注册到未声明的 slot 会抛错），但端到端展示仍建议用会话 fixture 覆盖。
   - 建议在 P4 之前补一个「会话日志 fixture」工具：构造一条含指定 Markdown 的 assistant 消息，放入临时 `DSH_HOME`，Playwright 打开会话并断言 `[data-nange-mermaid="diagram"] svg`。该工具对 Git/编辑器面板测试同样有用。
3. **无 i18n**：错误文案与按钮 aria-label 使用中文硬编码；正式插件应接 `ctx.locale` 命名空间。

## 4. 对后续的影响

- 纯客户端插件不需要 Typert 生成，构建链与安装链已稳定，可直接复用到 Git/编辑器面板的 UI 层。
- `client-ui-mermaid` 的 host entry 由 build-client 产出，证明「只有浏览器半边」的插件也能作为 Loader 行挂载。
- 正式 UI 插件需要 CSS Modules / 资产时，再引入官方 preset 适配（P4/P5 前评估）。
